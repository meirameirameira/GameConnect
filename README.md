## Objetivo
Criar uma plataforma online que reúne e organiza eventos relacionados a videogames, animes e quadrinhos, proporcionando uma experiência interativa e informativa para os entusiastas dessas culturas.

O foco é entregar:

* Acessibilidade
* Praticidade
* Confiabilidade
* Informação

  <h1 align="center">
    Tecnologias
</h1>

Algumas tecnologias que usamos foram:

### reCAPTCHA
Usada para diferenciar humanos de bots e proteger sites contra spam e ataques automatizados. Ele evoluiu desde desafios de texto distorcido (v1) para verificação com clique e imagens (v2) e, atualmente, utiliza análise comportamental avançada (v3) para identificar bots sem exigir interação do usuário. Baseado em aprendizado de máquina e redes neurais, o reCAPTCHA analisa padrões de navegação, movimentos do mouse e interações para determinar se a atividade é legítima, garantindo maior segurança com mínima fricção para usuários reais.

### Google Maps API
Permitindo a integração de mapas interativos, geolocalização e direções em aplicativos e sites, oferecendo funcionalidades como exibição de mapas personalizados, cálculo de rotas, visualização de trânsito em tempo real e busca por locais. Com suporte para diferentes tipos de mapas (como satélite e street view) e recursos avançados de geocodificação e autocompletar, a API é amplamente usada em serviços de logística, transporte e navegação.
